# ☕ Cafe Landing Page – Figma Design

A high-fidelity UI design for a modern cafe's landing page, created entirely in Figma. This project focuses on visual storytelling, user flow, and brand consistency — no code, just design.

## 🎨 Design Highlights

- Warm, earthy color palette with accent tones
- Custom typography pairing (serif + sans-serif)
- Hero section with promotional banner
- Menu card grid with item images & pricing
- Location & hours widget
- Contact / reservation CTA section
- Fully layered and organized Figma file

## 📱 Responsive Considerations

Designed with responsiveness in mind:
- Desktop (1440px)

## 🧩 Figma Features Used

- Auto layout for flexible components
- Text & color styles for consistency
- Component library (buttons, cards, nav bar)
- Prototyping with basic click-through flows

## 👩‍🎨 Purpose

This project was built to strengthen my UI design skills, explore cafe-themed branding, and create a portfolio-ready landing page concept.
